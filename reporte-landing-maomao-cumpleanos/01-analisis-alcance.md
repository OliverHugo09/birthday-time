# Análisis de Alcance

## Propuesta de valor principal
Landing page estática para visualizar los cumpleaños de personas importantes, con temática inspirada en Maomao (Los Diarios de la Boticaria). Los datos provendrán desde un archivo `data.json` (sin base de datos).

## MVP (Producto Mínimo Viable)
- [ ] Visualización de lista de personas con su fecha de cumpleaños
- [ ] Contadores regresivos: días, horas, minutos y segundos restantes hasta el siguiente cumpleaños (basado en fecha actual)
- [ ] Tema visual basado en Maomao: paleta de colores derivada del personaje
- [ ] Carga de datos desde `data.json` (estático)
- [ ] Diseño responsive básico
- [ ] Sitio 100% estático (HTML/CSS/JS puro, sin backend)

## Fuera de alcance (primera versión)
- Autenticación/usuarios
- Base de datos
- Añadir/editar cumpleaños desde UI
- Recordatorios/notificaciones
- Multi-idioma
- Animaciones complejas
- Integraciones externas
