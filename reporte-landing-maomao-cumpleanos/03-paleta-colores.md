# Paleta de colores basada en Maomao (Los Diarios de la Boticaria)

Basada en la estética del personaje: tonos terrosos, verdes apagados, dorados sutiles, con acentos en tonos berenjena/ocre. Paleta sugerida para primera versión:

| Nombre | HEX | Uso sugerido |
| :-- | :-- | :-- |
| Fondo principal | `#1a1814` | Fondo de página (tono sepia oscuro) |
| Superficie / Tarjetas | `#2d241b` | Contenedores, tarjetas de cumpleaños |
| Texto primario | `#f5e7d3` | Títulos, texto principal |
| Texto secundario | `#c9b99d` | Fechas, descripciones |
| Acento verde (hierbas) | `#7a9a56` | Botones, detalles decorativos |
| Acento dorado (medicina/tradición) | `#d9b75b` | Contadores, énfasis |
| Acento vino/berenjena | `#8c5a73` | Detalles decorativos, bordes sutiles |
| Éxito/Resalte | `#a9c27e` | Destacados |

> Nota: Estos valores son una propuesta orientativa; se pueden ajustar tras una revisión visual rápida, pero deben mantener la atmósfera terrosa/hierbática característica de Maomao.
